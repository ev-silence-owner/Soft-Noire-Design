# system/ — product contract under the Soft Noire umbrella

Root `tokens.css` is the public arrival / wallpaper palette (`#0A0A0B`, `#C6A15B`).
This directory is the ritual and product token set consumed by PatternLens and Ekran Zero
(`#0F0F14`, `#C9A84C`, GSE 60 000 ms). Do not flatten the two files into one without an NC.

| Path | Role |
|---|---|
| `tokens/` | SSoT CSS custom properties (phi, color, motion, theme, a11y, audio) |
| `kit/` | registry, oxlint adherence, UMD bundle, kit index |
| `prototypes/` | EntryGate / SesjaZero / Step1Rhythm Design Components |
| `docs/` | long-form canon (Ev_BIBLIA, technical spec) |

Product repos take a versioned tag `sn-v*`. They do not path-import this tree.
